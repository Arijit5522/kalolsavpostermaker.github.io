# ഉപജില്ലാ സ്കൂൾ കലോത്സവ പോസ്റ്റർ മേക്കർ | Kalolsavam Poster Generator (Bilingual: English & Malayalam)

A modern, high-resolution web app to create and download celebratory posters for the Kerala Sub-District School Kalolsavam (ഉപജില്ലാ സ്കൂൾ കലോത്സവം).

---

## 🌟 What's New & Key Features

1. **🌐 Bilingual Support (English & Malayalam)**:
   - Full toggle in header (`🌐 English / മലയാളം`) to switch the UI and poster presets instantly.
   - Independent **Poster Language Selector**: Generate posters in pure Malayalam, pure English, or custom bilingual.
   - Sub-districts, events, positions, and grades are translated in both English and Malayalam.

2. **✨ Clean & Authentic Design (No generic placeholders)**:
   - No more dummy text like "schoolname" or "student name".
   - Uses realistic defaults (*Devika S. Kumar*, *Mohiniyattam*, *Anjarakandy HSS*, *First Place 🥇*, *A Grade ⭐*).
   - Graceful empty state: If a school name or grade is not entered, the poster automatically formats without empty or dummy rows.
   - **Clean Badges Toggle**: Option to omit labels like "School:" / "Position:" and display sleek centered icon pills (`🏫 Anjarakandy HSS`, `🥇 First Place`).

3. **🎨 Designer-Grade Luxury UI**:
   - Glassmorphism dark panels with backdrop blur and golden amber radiance.
   - Studio lighting 3D canvas preview with live real-time rendering.
   - Quick event chips for 50+ Kerala Kalolsavam competition items (Dance, Music, Literature, Visual Arts).
   - 5 Color Themes (Royal Navy Blue, Festival Maroon, Emerald Green, Imperial Violet, Obsidian Gold).
   - 3 Canvas Aspect Ratios:
     - **4:5 Classic Poster** (Instagram post / Print)
     - **9:16 WhatsApp Status & Story** (Full screen phone status)
     - **1:1 Square** (WhatsApp DP / Profile)

4. **📸 Interactive Photo Adjustment**:
   - Drag to pan directly on the canvas to center the face.
   - Zoom in/out slider with percentage indicator.
   - 90° rotation button.
   - Paste photo directly from clipboard (`Ctrl + V`).
   - One-click "Try Sample Photo" button.

5. **⚡ School Batch Mode (Next Student)**:
   - "Next Student" button retains the festival details (sub-district, venue, dates) and school name, clearing only the student's name, item, and photo so teachers can rapidly generate 20+ posters in minutes.

6. **📥 Export & Share**:
   - Ultra HD PNG Download (crisp for print)
   - JPG Download (lightweight for sharing)
   - One-click "Copy to Clipboard"
   - Direct WhatsApp Sharing button

---

1. Open your browser and navigate to:
   **[http://localhost:8080](http://localhost:8080)**

3. Or open `index.html` directly in Chrome or Edge.
